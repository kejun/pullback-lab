# 本机验收工具交付记录

日期：2026-10-13。基线：`fd8593464a5f8de1f2dc0fff8599d84632e3e263`。

本批补充 KEJ-60 目标主机的证据收集工具和本机运行与恢复报告。没有把目标 Mac 已打开页面等同于部署、恢复或真实行情整体验收，也没有替用户更改实际部署、网络、VPN、凭据或数据库。

## 实现

- 新增 `acceptance:local` 命令。源 SQLite 只读；在线一致备份后只在全新副本恢复；不调用原库 Store、不迁移原库。
- 动态检查最新 schema，逐表核对冻结历史/证据、预留和预期的资金、计划、会话、命令与游标失效。后续新增不可变数据表自动进入恢复比较，不固定 schema 版本号。
- 数字 loopback 匿名健康/API/运维/SSE/编码路径检查；直连、不跟重定向、不传凭据、TLS 正常验证，外部来源在网络请求前拒绝。
- 严格字段白名单报告与短摘要，0700 结果目录、0600 文件、无覆盖，2.5 秒请求与120秒进程上限。完整私有备份留在本地。
- 无样本的恢复行为标为 NOT_APPLICABLE，CLI 源码与运行服务身份分开，报告保留未完成项目和 NOT_ACCEPTED 发布状态。
