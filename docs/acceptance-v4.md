# 第四批实现与验证

基线为已合并 PR 编号 3，主分支提交 `a261ff89de43f13176b978f2a1c79e1cf80b3192`。本批推进候选池与人工观察列表，关联 KEJ-50、KEJ-39 和 KEJ-59。真实权限、日历、单位、复权和数据连续性仍待取得证据；本批数据与性能验证使用合成样本。

## 实现范围

| 范围 | 实现与约束 |
| --- | --- |
| 有限研究池 | 单个添加及混合市场 CSV 预览；100 行、128 KB 请求边界；全批验证、去重后计算容量、同一事务提交。既有名称、标签、笔记与历史 ID 保留；旧裸美股代码按规范代码识别。 |
| 人工观察 | 人工身份独立于 PASS / FAIL / UNKNOWN；人工行不获得算法排名。标签、笔记和移除使用完整股票池版本校验，冲突后显式重读并保留草稿。有计划历史的记录不能删除。 |
| 筛选规则 | 可编辑美股及 A 股 ADV20 下限、ADR20 上下限与每市场数量；严格十进制校验、版本 CAS、不可变保存。新建或显式修订计划冻结规则快照，既有计划、支撑和回放依据不倒灌。 |
| 数据解释 | 每行显示数据截止、成交额来源与币种、缺失及未知原因；分市场覆盖、缓存计算时间与请求状态分开。采样 POLLING 或供应商 BACKOFF 独立于实时可用能力，配额未验证时保持未知。 |
| 一致性与缓存 | 单实例有界结果缓存，键包含完整源数据、规则、股票池与当下可见输入；旧 bar 内容修订、元数据修改和未来输入变得可知均失效。前端丢弃迟到请求，核对三接口的股票池版本及规则哈希；最多三轮读取仍不一致时保留完整旧快照并报错。 |

数据库迁移 v5 追加筛选规则表及不可变约束。升级旧 `screening_confirmed=true` 仅保存默认参数版本，确认时间为 `null`，标明来自历史确认标志；不伪造时间、不回填旧档案。旧一键确认接口重试不能覆盖新版本参数。真实来源缺乏证据时结果始终 UNKNOWN。

只有已完成且发生时间、接收时间均不晚于计算时间的日线参与。合成日线另按固定样本定义的完成时刻过滤；此规则不充当真实交易所日历。覆盖数只代表指标预热量足够，不证明数据权限或复权正确。

## 验证记录

执行 `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`，严格类型检查、生产构建、19 个文件的 200 项单元及集成测试、8 项浏览器测试全部通过。新增指标参数、原子导入、跨进程容量竞争、筛选版本与数据快照回归。浏览器场景使用各自的服务与临时文件数据库；当前环境为 Chromium 153.0.8010.0 与 Noto Sans CJK SC，CI 使用 Playwright 配套浏览器。

关键后端证据包括：第 100 只容量的两进程竞争、批量写入中途失败整批回滚、旧代码与元数据不覆盖、规则幂等与两连接 CAS、迁移失败回滚、旧计划原字节保留、人工 PASS 不排名、未完成/未来输入排除、旧 bar 修订与 worker 状态更新。

浏览器新增混合市场导入与去重、标签笔记刷新读回、观察内容及筛选规则的多标签页冲突、规则修改后 PASS/FAIL 切换、刷新失败保留结果、迟到响应与跨接口快照不一致的回归。旧研究、调价、持久演练、提醒恢复与反馈流程继续纳入完整回归；已查看实际页面截图。独立静态审查的并发与升级兼容问题已修复，无剩余阻断项。

## 性能与验收边界

基准运行采用文件 SQLite WAL/FULL、100 个合成标的、10 个同时活动计划、30 轮与 300 次归档。冷请求是元数据修改后的应用缓存未命中，热请求显式断言命中；不宣称清空进程、JIT 或操作系统缓存。任何请求失败、不完整结果或审计不匹配都会中止报告，成功报告列出成功和失败计数。

原始报告见 [benchmark-v4.json](benchmark-v4.json)。运行基于本地提交 `0eae6a5995adcf52fd67e5151d7dcb3839c11045`，当时已跟踪文件无未提交修改；后续仅追加本报告。发布时校验远端代码树与本地一致，提交映射记录在 PR。运行环境为 Node 24.19.0、SQLite 3.53.4、Linux、AMD EPYC 9V74；使用带鉴权的 Fastify HTTP 处理器，不含 socket 传输。

| 指标 | P95 |
| --- | ---: |
| 100 标的，应用缓存未命中 | 1290.675 ms |
| 100 标的，应用缓存命中 | 145.719 ms |
| 10 个合成计划回放入库 | 196.150 ms |

候选请求 60 次成功、0 次失败；300 次归档审计全部 MATCH，审计零写入。缓存页本机 P95 小于 2 秒，10 计划历史回放 P95 小于 5 秒。

本地性能不能代替真实上游延迟、生产网络、目标磁盘或连续收盘输入到提醒的 SLA；供应商请求与失败数未测量时为 null。部署主机、OpenAPI 凭据和逐市场证据未提供，因此相关工单保持进行中，不关闭真实验收门槛。
