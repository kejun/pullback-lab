# 第十一批实现与验证

基线为已合并 PR 编号 10，主分支提交 `70e78f4d641158063a2b6362fd164cb496684be1`。原 PR head 的 CI / verify 与 CI / deployment 已重新核验通过。本批推进 KEJ-47 的分钟证据持久化与 KEJ-59 的验收记录。

## 实现

- 增加显式分钟证券清单，最多十只，仅请求当前研究池中的合法真实证券。清单不自动扩展研究池，默认关闭，配置错误在修改数据库前拒绝。
- 同一 worker 收集日线及所选证券的 1/5 分钟历史，共用配额、限流、单请求通道、超时及停止机制。逐请求重查研究池，分钟样本始终隔离，不进入正式行情或信号通道。
- 按证券、周期保存独立接收进度和请求摘要，区分已收样、空结果、失败及中断。单根接收、进度、计数原子保存；后续失败保留此前证据。进程重启后失效遗留请求中状态。
- 结构 v8 保留旧日线进度及私有已接纳位置，迁移前备份与事务回滚保持。原始证据表不改写。
- 设置抽屉显示各周期结果、时间和隔离原因。鉴权和禁止缓存保持，公开范围有限的运行诊断继续排除证券资料。新增浏览器场景使用独立数据库和离线供应商夹具，通过真实状态接口读取。

## 验证

新增配置、分钟采样和升级验证覆盖默认关闭、最多十只、证券身份、共享请求间隔、各周期独立进度、重复接收、空结果、周期不匹配、已确认分钟仍隔离、数量上限、移出研究池、超时不叠加、停止及晚到结果、数据库失败回滚、重启关闭采样、旧库备份和迁移失败回滚。

完整单元及集成回归为 32 个文件、366 项。新增 1 项浏览器验收，完整浏览器套件为 15 项；校验真实鉴权状态接口、三种逐周期结果、失败后旧界面保留和 390px 手机布局，保存桌面及手机的逐卡片完整截图，断言卡片处于抽屉可见区域内，并记录浏览器版本和实际渲染字体。CI 另执行容器持久化、重启读回、在线备份和恢复。

本地 Chromium 151.0.7922.34 版本可读取，但启动被环境的 socket 权限限制阻止，因此不声称本地浏览器验收通过。浏览器和容器检查使用当前 PR head 的 GitHub CI；未运行结束不得算通过。最终已提交源码 SHA、干净工作区、逐项命令退出结果和 CI 结果记录在 PR 与 Linear。
