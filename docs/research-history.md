# 人工历史资料与研究图表

在候选池添加人工观察标的后，打开同一个「标的与计划」页面。在「人工历史资料」中下载 JSON 模板、填写自己已核对的数据并选择文件。选文件只在浏览器本地读取；点击「只读预览」才上传至本应用。预览不会写入数据库。核对预览、勾选声明并点击「确认导入历史资料」后才原子保存。

成功后，原有日线、1 分钟、5 分钟图直接显示统一拆股尺度的资料。可以选择日线锚点、调整计划价格、查看支撑数值并保存草稿。导入与「用于当前计划草稿」都是明确采用新资料的操作，保留原价格和锚点输入；使用者需要重新核对它们是否适合新价格尺度。旧计划不会自动改用新资料。

## 身份和边界

这是人工提供的历史研究资料，不是 OpenAPI 授权或行情来源认证。公司行动的 COMPLETE 与日历 verified 是人工核对声明。数值一致不能证明资料真实、历史完整、供应商授权或逐笔连续。正式候选筛选资格、真实监测和行动提醒仍保持门控，不接券商交易接口，不设置风险参数默认值。

每根资料的 receivedAt 由服务端设置为实际导入时刻，不能由文件回填成过去。分钟 AVWAP 是用这次导入的历史日线事后重建，图表持续显示「人工历史重建 · 非当时已知」。它投影分钟开始前已结束的最后一根日线 AVWAP，不用分钟重新计算，也不把实际导入时间伪称为当时已收到。页面逐点显示精确值和日线完成时刻。导入不产生提醒、不重播机会、不更新资金。

## 填写模板

模板故意保留空日期、空价格和来源占位，不能直接作为行情导入。有公司行动存档时，模板会带上当前清单和来源原文，仍需重新核对。来源文本的 SHA-256 由服务端计算，不要求手工生成。

- 最大文件为 2 MiB，最多 3000 根 K 线和 1000 条日历资料。价格、股数、成交额必须使用十进制字符串，不使用 JSON 浮点金额。
- instrumentId 必须是当前观察标的；不能覆盖 DEMO 合成示例。source 填实际量价来源，reviewer 填核对人，targetDate 填交易所当地的目标日期。
- 所有 start、end、knownAt、publishedAt、effectiveAt、coverage.from、coverage.through 均为 UTC 毫秒。calendarDays.date 和 bars.sessionDate 是交易所当地日期；intervals 是当地常规交易时段。
- 日历需明确提供每根日线及目标分钟会话的日期、时段、来源、版本与可知时间。美股时区按日历模块换算夏令时，A 股午休需列成两个时段，不能把工作日等同开市日。
- bars.period 只能是 1D、1m、5m；id 逐根唯一，revision 表示来源版本。final 必须为 true，adjustment 必须为 RAW。只接受已经收盘的会话。
- bars.volumeUnit 为 SHARE 时 volume 是股数；为 LOT 时另填正整数 lotSize。原始量必须为整数。turnover 是该线的实际成交额，不能用收盘价乘量冒充。
- 至少包含一根目标会话之前的日线、同目标会话连续五根 1 分钟线及对应的一根 5 分钟线。可以有多组完整窗口，但 1 分钟聚合的 OHLC、股数、成交额必须与每根 5 分钟线精确相等。缺根、重复窗口、错周期、跨午休、未闭合均拒绝。
- corporateActions 复用现有公司行动契约：source、coverage、actions、removedActionIds 和 documents。覆盖从最早日线到目标会话收盘；documents 包含 id、HTTPS url、publishedAt、原文 content。actions 中保留 id、revision、kind、effectiveAt、publishedAt、documentIds；拆股还需 sharesAfter、sharesBefore。
- 确认没有拆股也需要完整覆盖的实际来源依据。未知不能填成 COMPLETE。删除已存公司行动必须在 removedActionIds 明确列出；同一行动的修订冲突会拒绝。与已有存档的并发变化必须重新预览。

预览错误会给出字段路径或稳定原因码。常见情况：MINUTE/SESSION 错误应检查 UTC 时间和市场常规时段；CROSS_PERIOD_VALUE_MISMATCH 应核对原始量价和实际成交额；CORPORATE_ACTION_COVERAGE_UNKNOWN 应补足公司行动覆盖，不能用放宽比较误差解决。

## 版本、保存和修订

预览固定当前历史资料 ID 和公司行动版本。导入再次读取它们；另一个标签页先写入时返回 409，旧资料与草稿不变。相同成功请求重试只返回原结果，不重复写入。导入动作将公司行动、历史原文、标准化量价、统一拆股值及相关计划暂停一起提交，任一步失败全部回滚。

每份历史资料不可变，保留实际导入时间、完整来源、行情与公司行动版本及内容哈希。计划保存要求明确指定当前 historyId，冻结日线、支撑和完整计划版本。后来导入修订或公司行动变化，旧计划的原始输入和旧图仍可查阅；旧图会标为已替代，不能直接覆盖保存。需采用当前资料并保存新版本。资料清单本轮最多展示最近 20 份元数据；已保存计划仍通过精确 ID 引用旧资料。

数据库结构 v10 只新增不可变历史资料表和索引。正常启动仍先备份旧库，备份失败则停止迁移；新资料随在线备份及新文件恢复保留。历史数据无删除入口，有存档的证券不能从观察列表移除。
