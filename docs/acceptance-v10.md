# 第十批实现与验证

基线为已合并 PR 编号 9，主分支提交 `08398c793afc0cf149e6d0a5e481a7f6c94575b4`。本批推进 KEJ-48 的跨周期价格尺度契约与 KEJ-59 的可重复审计。

## 实现

- 只读审计所选日线、1 分钟和 5 分钟窗口，使用固定公司行动版本调整至已收盘目标会话的价格尺度。保留原始价量、反向调整股数，不改实际成交额。
- 复核证券、来源、真实/合成身份、股数单位、原始口径、OHLC、最终状态与交易会话。分钟聚合必须完整，逐字段精确比较 5 分钟样本；不以容差掩盖差异。
- 拒绝单根 K 线内部拆股、目标会话内尺度变化、未来或未收盘会话及覆盖不足。失败返回 UNKNOWN 且不输出部分调整数据。
- 固定系统接收截止、行情水位、输入序号、公司行动版本和日历资料；在一个 SQLite 读取事务中检查哈希、已知修订与冲突。当前最新公司行动状态单列，不混入历史指纹。
- 新增 `basis:audit` 命令，不创建、迁移或写入数据库，不连接供应商，不改变实时能力。输入有大小与数量上限，失败不回显私有内容。结构 v7 只增加接收查询索引，正常升级继续先备份旧库。

## 验证

新增 18 项数值与会话测试、6 项持久化/独立进程验证。完整单元及集成回归为 31 个文件、343 项。

覆盖正向拆股、反向拆股、现金分红、A 股午休日历、双市场样本、实际成交额、混合单位/来源/证券、迟到或未闭合线、缺分钟、聚合差异、未完成目标会话、单根线内部行动以及后来才可知的修订。固定样本的 5 分钟预期值独立给定。

持久化验证覆盖只读连接零写入、服务锁兼容、关闭数据库文件字节不变、同毫秒新增修订后的固定历史输出、已知冲突与过期修订拒绝、缺失输入和证据、未知水位、输入顺序规范化、私有错误不回显、缺失数据库不创建、输入大小和符号链接拒绝。v6 迁移前命令拒绝执行；正常备份并升级后旧数据完整，查询计划实际使用新索引。

最终已提交源码的 SHA、工作区状态、类型检查、完整测试、生产构建、差异检查和 CI 结果记录在 PR 及 Linear。CI / verify 执行完整浏览器回归；CI / deployment 验证镜像构建、持久化重启及备份恢复。未结束或无法核验的检查不得算通过。

## 未完成边界

本批输入全部为明确标记的合成资料。CONSISTENT 仅表示所选窗口数值与尺度自洽，不证明来源真实性、公司行动完整、5 分钟数据独立性、全会话连续性、未来目标会话或真实提醒能力。日历 verified 仍为外部提供的依据声明，不能由命令自动认证。

真实行情持续接入、隔离样本的正式核验、真实公司行动与目标会话变化验证、正式图表/指标派生、目标主机部署与真实端到端延迟仍待完成。相关整体工单保留 In Progress，`liveEligible=false`。
