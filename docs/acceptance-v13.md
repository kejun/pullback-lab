# 第十三批实现与验证

基线为已合并 PR 编号 12 的主分支提交 `17a0a718f0ad8d44fd24d70d20d0d6651dfc3db4`。基线原 head 与合并提交的 verify、deployment 均已核验成功。本批推进 KEJ-52 图表与计划编辑、KEJ-51 不可变支撑快照及 KEJ-59 验收。

## 实现

- 现有研究页提供人工历史 JSON 模板下载、本地选文件、明确只读预览及确认后的原子导入，不增加工作页。文件 2 MiB、3000 根上限，详细字段错误、来源占位拒绝、取消/迟到响应及切标的隔离。
- 复用公司行动存档、显式市场日历、量价规范化和跨周期尺度核验。验证原始量价、股数单位、最终状态、目标会话收盘、1 分钟聚合与 5 分钟精确一致；失败不发布部分图表。资料、公司行动及相关计划暂停共同提交。
- 接入原日线/分钟图表、日线锚点和计划价格草稿。所有实际接收时刻来自服务端导入时间。分钟 AVWAP 按当前历史资料投影上一完成日线，明确标注事后重建、不表示当时已知，提供精确值与完成时刻。
- 数据集和原文不可变，内容哈希、预览令牌、历史/公司行动双版本冲突与成功重试保护；预览令牌绑定恢复代际，旧预览和旧重试不能跨数据库恢复继续。保存计划需明确指定当前 historyId，冻结日线及支撑；后来的修订不改变旧计划或旧图，旧资料只能只读查阅，需重新采用当前资料才能保存新版本。
- 独立审查发现并修复了旧资料与当前候选指标混用、模板重复撤回公司行动及极端拆股后数值超出计算边界的问题；已补未被计划引用的旧资料只读入口。
- 结构 v10 保存人工历史数据集，保持迁移前备份和失败回滚，在线备份/新文件恢复保持原输入和不可变约束。
