# 第九批实现与验证

基线为已合并 PR 编号 8，主分支提交 `b1628adcb17b478b0a72a5efa17d6156965716ed`。本批推进 KEJ-48 的公司行动证据核验入口、KEJ-50 的观察列表历史引用保护，以及 KEJ-59 的只读与浏览器验收。

## 实现

- 研究页新增按需展开的公司行动证据面板，展示来源、人工核验、覆盖声明、行动生效及发布时间、材料摘要与原文。
- 版本历史按收录序号分页，每页固定 20 条；同毫秒导入仍有稳定顺序。列表不传正文，正文逐份按需读取，所有接口均需登录并禁止缓存。
- 比较所选版本和前一收录版本，逐项展示来源、覆盖、核验人、行动和材料的新增、修订与移除。查阅旧版本不改变当前图表、计划、资金或行情能力。
- 原文以 React 文本节点显示，来源链接使用 HTTPS 并隔离新窗口。切换证券、版本、刷新和收起会取消旧请求；列表、详情和原文分别提供失败重试。
- 已有公司行动证据的证券返回明确的 409 删除冲突，保留证券和历史引用；观察笔记仍可修改。未新增数据库结构、行情接入或网页写入入口。

## 验证范围

新增 12 项接口测试，完整单元及集成回归为 29 个文件、319 项。覆盖三类接口鉴权、空记录、非法游标、固定分页上限、并发追加期间分页稳定、同毫秒排序、跨证券版本拒绝、原文按版本保真、比较中的修订/新增/移除、所有读取零数据库写入和删除冲突零变更。

新增 2 项独立浏览器场景，完整浏览器回归共 14 项。使用独立文件数据库，在启动服务前导入明确标为合成的 22 个版本，不增加测试专用写入 API。浏览器验证按需加载、历史翻页、差异展示、纯文本 HTML、历史原文、三个层级的失败重试、迟到响应隔离、未知空态、删除阻止以及研究快照不变。桌面与手机宽度的面板已截图检查。

本地浏览器为 Chromium 153.0.8010.0，已实际启动并核实中文使用 Noto Sans CJK SC。最终提交执行 `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` 和 `git diff --check`。已提交源码 SHA、完整退出结果、远端代码树映射及 PR 当前 head 的检查结论记录在 PR 和 Linear 中。

PR 的 CI / verify 重新执行完整测试与浏览器验收；CI / deployment 执行镜像持久化、重启、备份和恢复检查。尚未结束的检查不得视为通过。

## 保留的未完成范围

本批使用合成资料，没有导入或核实真实发行人公告，没有执行供应商实测或目标主机部署。COMPLETE 仍只是人工窗口声明，哈希只证明内容一致；所有证据响应均为 `liveEligible=false`。

真实公司行动覆盖、量价单位与跨周期/目标会话尺度、真实行情接入、生产端到端延迟和目标主机故障验收仍未完成。不新增性能或盈利结论，相关工单保持进行中。
