## 一致性规则

调价接口读取服务端证券规则。POINT 是绘制坐标的十进制文本提议，按最近 tick 舍入，半 tick 向上；STEP 从已在 tick 上的精确文本价格增减整数个 tick。价格计算使用 64 位十进制上下文，拒绝丢失增量的结果。接口本身不保存计划。前端保留后续人工输入，丢弃标的、周期、计划版本或编辑代际改变后的迟到响应。

分步入口不接受客户端提供行情、通过结论或时钟。准备时冻结合成市场输入与配置；每个 BAR 到达处理边界时，在同一写事务中读取当前资金和其他计划预留，生成风险门，运行纯核并提交技术事件与预算影响。重复同一输入幂等；同一输入标识对应不同内容时暂停。多标签页推进使用 expectedVersion、expectedAttemptId 和 expectedStep，不自动重试冲突。

截止 CLOCK 使用明确的合成时间，严格晚于截止时间加宽限期才过期。服务端定时器只检查已持久化的合成时间，不会用当前墙钟使历史样本立即过期。重启生成运行代际，未完成尝试暂停，用户必须显式建立新尝试。已命中的记录及预算不会因重启自动释放。

时钟过期后收到的迟到技术条件只产生 `LATE_TECHNICAL_REFERENCE`，不能填写入场反馈、不能恢复预留，也不能将 EXPIRED 改回可执行状态。原纯核事件完整保留在输入归档中。已命中之后的输入可继续产生突破回落、止损参考事件，不能重复入场。

提醒列表和 bootstrap 返回最多 50 条摘要，SSE 每批最多 10 条变更。历史页使用事件序号；变更游标包含数据库代际和变更序号。备份恢复旋转代际，未知或异库游标要求重新读取快照。快照内容、统计和水位在同一读事务中获取，避免快照与重连之间漏事件。前端按事件 ID、变更序号合并，普通断线保留已读旧页和反馈草稿；恢复到另一数据库代际时替换服务端缓存，并要求重新核验反馈版本。

## 验证

严格类型检查、生产构建、17 个测试文件的 181 项单元及集成测试、6 项浏览器测试通过。执行命令为 `npm run typecheck`、`npm test`、`npm run build` 和 `npm run test:e2e`。当前浏览器为 Chromium 153.0.8010.0，中文字体为 Noto Sans CJK SC；CI 使用 Playwright 配套浏览器。远端结果按 PR 当前提交单独核验。

14 项运行器测试覆盖接收顺序与哈希、相同输入幂等、冲突暂停、两连接推进 CAS、事件插入失败原子回滚、重启前后预算保留、截止宽限、单根迟到、不经 CLOCK 的迟到、资金代际改变和 STALE 阻断、触发后参考事件、完整序列与无回踩最终 CLOCK。分步归档逐事件审计为 MATCH；纯核与旧版审计没有修改。

5 项事件流测试覆盖 123 条大快照的分页摘要、正反游标、摘要不泄露完整输入、按需详情、已读与旧页反馈同步、v3 库升级、异库和恢复游标、HTTP SSE 鉴权及失效、真实 socket 背压和有界关闭。既有数据库故障、进程锁、只读审计和反馈版本冲突测试继续纳入完整回归。

浏览器新增鼠标/键盘/真实触摸调价、取消零提交、迟到调价不覆盖新草稿，以及分步推进、刷新读回、SSE 同步、按需详情、断线和登录恢复后草稿保留。原研究与反馈旅程继续运行。各场景使用独立服务与临时文件数据库，避免预设确认和计划状态跨用例污染；390px 窄屏无横向溢出。

本批未增加新的生产性能结论；上一批文件数据库测量范围和局限见 [acceptance-v2.md](acceptance-v2.md)。目标主机和真实行情凭据尚未提供，部署、权限、单位、交易日历、复权、闭合消息及连续性证据仍由未完成工单跟踪。
