# 第七批实现与验证

基线为已合并 PR 编号 6，主分支提交 `1dc1af184969f500d511bd1e1f6ef24a332ab4a8`。已核对该 PR 的 CI / verify 与 CI / deployment 均通过。本批推进 KEJ-46 的行情证据探针、KEJ-47 的采样生命周期，以及 KEJ-59 的异常验收。

## 实现与原问题

| 范围 | 原问题 | 本批行为 |
| --- | --- | --- |
| 分步证据 | 任一步失败会终止整个探针；尚未汇总的日线和日历结果可能丢失 | 每步立即保存结果；行情等级和套餐拆开；每证券分别请求静态资料、报价、日线、1/5 分钟；各市场日历独立记录 |
| 结果解释 | 空观察与执行成功缺少独立状态 | SAMPLED、EMPTY、FAILED、TIMED_OUT、SKIPPED 分开，保存时刻、耗时和稳定原因；闭合延迟仅记未经时钟和语义验证的原始时间差 |
| 证据落盘 | 只有最终标准输出，中途失败缺少可恢复记录 | 可选新建 0600 JSONL 检查点，每步追加并同步；拒绝覆盖旧文件，写入失败停止采样，最终仍输出完整 JSON |
| 请求等待 | worker 运行中可永久停在 POLLING | 初始化与请求默认20秒等待上限；超时进入退避，旧请求未结束时不重叠重试；迟到结果不直接落库 |
| 停止与清理 | 关停要等外层超时；退订失败可能跳过其他证券 | 停止立即取消应用侧等待；订阅和退订分别限时，尝试清理所有证券，废弃旧回调；迟到订阅确认尝试补偿退订 |

探针失败只输出稳定原因码，不输出原始供应商错误、环境凭据或私有输出路径。JSONL 包含所选证券与行情样本，应按供应商留存许可私有保存。样本采集和正式能力验收分开：两市场仍为 UNKNOWN，真实分钟监测与行动提醒未开放，生产日线采样仍默认关闭并保持隔离。

## 验证范围

- worker：请求超时后离开 POLLING，原调用未结束时无重复初始化或请求；迟到成功不直接写入，迟到拒绝不形成未处理异常；停止时清除等待计时器，库关闭后不再落库。
- 探针：两市场与三个周期覆盖；部分失败保留前后独立证据；超时停止新调用；空样本独立标记；无凭据、重复证券和非法参数不初始化 SDK；检查点失败停止后续采样；单通道请求间隔。
- 订阅：正常退订、部分订阅失败、全部清理尝试、退订失败/挂起、迟到确认补偿、回调失效、并发观察拒绝、推送错误及非法时长。
- CLI：独立进程有外层超时，缺凭据退出2并输出可解析报告；0600 检查点、已有证据不覆盖、非法参数不回显敏感值。
- 回归：类型检查、生产构建、26 个文件共269项单元/集成测试和12项浏览器测试。浏览器沿用6个独立服务及数据库，无新增页面流程。

验证环境：Node 24.19.0、SQLite 3.53.4、Chromium 153.0.8010.0。通过实际浏览器启动与 CDP 字体检查确认中文使用 Noto Sans CJK SC。验收使用锁定依赖，无真实 OpenAPI 调用；缺凭据 CLI 和其他异常由合成适配器或独立子进程验证。最终源码 SHA、完整退出结果与远端当前 head 的两项 CI 记录在 PR 和 Linear 中。

## 剩余条件与下一步

应用侧超时不证明供应商已取消原调用。原调用永久不结束时采样保持等待/退避，需排查网络或重启；CLI 输出完成后退出自身进程。Node 定时器依赖事件循环正常运行，不构成对原生同步阻塞、系统休眠或主机卡死的时间保证。

仍需应用自己的 OpenAPI 凭据、目标主机地区、权限、单位、交易日历小时、复权和公司行动来源、闭合推送语义及连续性证据。然后才能将已验收分钟数据接入持久运行边界。未运行真实权限采样，未部署目标主机；真实 TLS、代理链 SSE、断网/休眠/断电、异地恢复和端到端延迟继续待验收。本批不产生新的性能或真实行情 SLA 结论，相关整体工单保持进行中。
