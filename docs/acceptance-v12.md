# 第十二批实现与验证

基线为已合并 PR 编号 11，主分支提交 `fd9317af107457d76ca0c7c6fb48add103075b58`。原 PR head 的 CI / verify 与 CI / deployment 已重新核验通过。本批推进 KEJ-47 的行情回执核验及 KEJ-59 的存档验收。

## 实现

- 设置抽屉增加按需加载的采样回执浏览、原文哈希核对、同根前序比较和当前报告 JSON 下载。区分本地内容变化与供应商确认修订。修正 PR 编号 11 的评审问题，将「最近轮询完成」改为「最近成功轮询」。
- 私有只读接口每页 20 条，首次读取固定快照；分页和详情校验证券、请求周期、数据集版本与收录上限。恢复后拒绝旧快照。列表不读取原文到应用，单条原文读取上限 64 KiB。
- 新回执保存请求周期，错周期响应仍归属原请求。结构 v9 不倒填旧请求周期，不改写旧原文字节与哈希；旧记录可通过「请求周期未知」查阅。增加列表和精确前序索引。
- 哈希异常、不可读或过大时保留明确状态，不生成可信比较。前序按原文身份和本地接收顺序查找，重复接收不因接收时间改变而显示为内容变化。

## 验证

新增 18 项单元与集成验证；完整套件为 33 个文件、384 项。覆盖鉴权、禁止缓存、固定分页、并发新增、非法参数、范围隔离、恢复快照失效、精确前序、旧版周期未知、错周期归属、原文保真、哈希异常及大小限制、读取零写入、v8 备份保真和 v9 迁移回滚。查询计划确认列表和前序索引被使用；原有 worker 测试补充请求周期断言。

新增 2 项浏览器场景，完整套件为 17 项。离线适配器通过真实 worker 保存 22 条合成回执，启动前另加一条明确模拟旧版的回执。通过真实鉴权接口核对延迟加载、原文纯文本、前序差异、下载保真、分页、旧记录、空存档、列表/详情/分页失败重试和迟到响应隔离。保存桌面与 390px 手机宽度的完整核验卡片截图，并记录浏览器版本与实际字体。

本地 Chromium 受环境 socket 权限限制无法启动，不计作本地浏览器通过。浏览器与容器部署检查通过当前 PR head 的 GitHub CI 验证；只有运行结束且必需检查全部成功才算通过。最终已提交源码 SHA、工作区状态、命令退出结果、CI 日志和截图检查记录在 PR 与 Linear。
