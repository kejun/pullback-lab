# 正式收盘运行链：服务端适配器契约

本模块补齐正式输入到行动事件的服务端链路，不表示真实 Longbridge 接入已经验收。默认启动没有 `ClosedBarAdapter`，所有真实市场能力继续关闭。没有 HTTP 行情输入、证明上传或“已验证”开关；分钟采样隔离库、人工历史资料、JSON 导入及合成回放都不能授权正式运行。

## 信任边界与接线

已审计的服务端适配器通过 `createApp({ closedBarAdapter })` 注入。它必须提供实际探针报告标识、逐证券规则证据、完整日线和仅拆股价格口径证据、当前会话日历及带有效期的能力事实。运行器复用能力评估与日历解析，深拷贝并冻结上下文；真实适配器本身仍待完成和实测，当前唯一实现是测试目录中的隔离契约夹具。

上下文最多覆盖十只已经在研究池内的证券。日线必须至少250根、最终确认、来源及价格基准一致、选择时已知，不能带合成标记。服务端保存的上下文与日线/证券规则摘要必须精确吻合，支撑快照额外冻结上下文ID。证明失效、规则或日线变化、人工历史资料引用都会阻断正式启用。客户端提交 `verified`、`capability` 或资料ID不会改变此边界。

`start` 只打开只读连接，`setSubscriptions` 根据已提交的活动尝试更新实际订阅，暂停、到期和反馈结束后退订。外部调用不占用数据库事务；握手与订阅更新有界、单通道，超时不表示底层请求结束。旧回调按连接代际隔离，停止后的晚到成功再次清理连接。默认等待上限20秒，关闭等待上限2秒；适配器仍须实现可靠的关闭行为。

## 从接收到账本

1. SDK适配器回调进入后由服务端捕获实际 `receivedAt`，持久保存不可变回执、内容哈希、连接代际和递增序号。接收时间不接受客户端或供应商代填。
2. 处理器按本服务所有者的持久序号读取；不能消费其他活动所有者的队列。分钟复用标准化、不可变修订仓库和开盘对齐的5分钟聚合。重复保持首次接收时间；不同修订/内容、乱序、缺口、迟到、权限失效和断线停止连续性。已确认无成交有独立覆盖事实，绝不补造OHLC。
3. 每条处理事务同时更新分钟完整性水位、尝试输入/状态、消费标记、资金预留、事件、通知与回执处置。故障可重试待处理回执；重启却不能重放旧机会，旧待处理输入改为历史归档。
4. 复用既有纯状态机。前15分钟采用1分钟，此后到第60分钟采用5分钟；09:45候选的参考由09:40–09:45完整子分钟组成。参考和最后闭合接收的30秒边界均包含等号。
5. 真实定时器先处理已持久接收的输入，再提交截止事实。服务器时钟倒退先暂停，不先消费技术机会。数据暂停保留预留，直到用户暂停或观察期限结束；行动提醒待反馈不因首小时结束释放。

## 技术消费、报价与资金

`receivedAt` 只决定市场输入是否及时；`decisionAt` 决定当前可行动资格。队列中的及时闭合线不会因计算延迟改写接收时间，但必须重新核对当前报价、资金、计划版本、证据和当前完整性。

已经接收到的止损报价、止损闭合线、参考修订或缺口优先于旧排队突破。止损触及后的反弹不清除已知失效事实。后续报价不扩展分钟覆盖，也不能让不完整LOD通过追高检查。

当前契约的报价必须落在已验证的常规会话区间内，是最后成交价估计，事件明确提示不保证可成交；未把它冒充新鲜最优卖价。正式风险调用实际资金和汇率时间，要求当前会话确认，绝不使用合成回放的时钟重映射。数量上限同时受原批准数量和当前预留数量约束；一次资金重建缩量后，触发不能恢复旧数量。风险复核和替换本计划预留在同一 `BEGIN IMMEDIATE` 内，包含其他计划当前占用。资金、报价或入场门控失败仍保存技术消费及 `ENTRY_BLOCKED`，不会静默重试。

`TECHNICAL_TRIGGERED` 与 `ENTRY_TRIGGERED` 沿用尝试级唯一约束，通知写入失败整体回滚。事件沿用现有分页、SSE游标恢复和反馈处理。正式事件的只读审计重放冻结纯核输入，并用原 `decisionAt`、报价、资金和预留重算风险；没有生产发布出口。

## 启用与恢复

- `POST /api/plans/:id/activate`：既有鉴权、CSRF、计划/尝试CAS与幂等命令；非演示证券转入正式运行器。
- `GET /api/plans/:id/monitor`：只读连接、逐标健康及持久尝试进度。
- `POST /api/plans/:id/monitor/recover`：携带 `expectedVersion`、`expectedAttemptId`、`sourceAttemptId`、`expectedWatermark`，只能从最新未消费尝试显式恢复。

首次模板可在开盘前启用。开盘后启用必须有完整的此前未触碰证据，含正在进行的部分分钟；当前闭合分钟契约不能补造这部分证据，所以覆盖不足明确拒绝。恢复创建新尝试和新证据代际，仅接受激活水位以后开始的完整分钟，必须重新观察严格高于支撑上沿后再回踩。旧上方证据、触碰、参考、迟到队列和旧连接回调都不继承。

## 发布仍受阻的外部条件

还没有生产 Longbridge 适配器、真实权限/地区/单位/最终状态/完整性与公司行动来源验收；未配置长期凭据，未部署目标主机，未进行交易。真实端到端延迟、代理SSE、目标主机磁盘/断网/休眠、真实备份恢复和持续连接可靠性仍待验收。代码和隔离夹具通过不会让上述条件自动变成通过，也不会完成盘中逐笔模式。可选的距日内低点追价限制与完整费用表已接入不可变计划版本、用户表单及正式配置；开关和参数由用户填写，低点覆盖不足仍阻断。详见 [plan-controls.md](./plan-controls.md)。
