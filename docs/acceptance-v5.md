# 第五批实现与验证

基线为已合并 PR 编号 4，主分支提交 `e69a349174c0f191d53728b2fb8fbece6b42440b`。本批推进 KEJ-60 的私有部署、备份恢复和运行状态，并补充 KEJ-59 与 KEJ-43 的恢复验收证据。没有选择或修改真实部署主机，没有开放真实行情能力。

## 实现范围

| 范围 | 实现 | 验收边界 |
| --- | --- | --- |
| 备份与恢复 | SQLite Online Backup、0600 暂存、schema/完整性/外键校验、无覆盖原子发布与 fsync；恢复只到新目标并持有服务锁 | 包含已提交 WAL，不复制正在写入的主文件；拒绝硬链接源、现有目标和侧车路径冲突 |
| 升级保护 | 生产配置预检在取得服务锁与打开业务库之前；迁移旧库前生成唯一备份 | 备份失败阻止升级；备份保持旧 schema，源库不预先迁移；未进行目标主机断电实验 |
| 恢复后状态 | 追加资金 STALE 代际、暂停未完成计划、清旧会话与幂等命令、旋转提醒游标 | 保留历史计划、资金快照、事件、输入、反馈及 TRIGGERED / TAKEN_PENDING 占用；新恢复命令不依赖手工环境开关 |
| 运行状态 | 登录后只读诊断接口、设置页按需读取与 JSON 下载、失败保留旧时间与报告、迟到响应保护 | 只返回白名单汇总，不含金额、标的、笔记、凭据、路径或原始错误；市场、时钟及公网 TLS 验证保持 UNKNOWN |
| 部署配置 | 非 root 容器、只读根目录、本地持久卷、单实例、退出守护、Caddy HTTPS 与 SSE、仅代理发布端口 | 本机没有 Docker/Caddy，实际容器验证由新增 CI deployment job 执行；真实域名、证书、主机重启和异地恢复仍需现场验收 |

`npm run backup -- NEW_BACKUP_PATH` 保留在线一致快照。`npm run restore -- BACKUP_PATH NEW_DATABASE_PATH` 在暂存副本上升级及失效旧状态，成功后再发布。失败可保留已释放的服务锁文件，不能删除锁文件来规避占用。备份包含私密研究与资金内容，应与可下载的脱敏诊断报告区别保管。

独立审查复现并修正了两项路径风险：硬链接源可能对应不同 WAL 名称；目标若与源的 WAL 等侧车重叠，备份可能被后续 SQLite 打开操作删除。实现现拒绝主库及锁文件侧车命名空间的双向重叠。明显无效的 HOST 格式也在写库前拒绝。最终静态审查无剩余阻断项。

## 本地验证

`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` 全部通过。最终为 22 个测试文件、221 项单元及集成测试、10 项浏览器测试。环境为 Node 24.19.0、SQLite 3.53.4、Chromium 153.0.8010.0 与 Noto Sans CJK SC。已查看运行状态截图；各浏览器项目使用独立服务及临时文件数据库。

新增 12 项备份恢复测试覆盖在线 WAL 与另一连接未提交写入、两个并发目标写入、0600 与单文件发布、坏库/外键/改变 schema 的拒绝、旧版本副本迁移、源库字节保真、恢复状态与待反馈占用、CLI 错误脱敏、自动迁移备份和未来 schema 拒绝。4 项启动测试覆盖预检无副作用、配置拒绝与备份失败不升级；5 项诊断测试覆盖鉴权、白名单脱敏、读取零写入、磁盘未知与实际容量及兼容恢复分支。

新增 2 项浏览器测试覆盖设置按需请求、完整下载内容、无敏感字段、读取不改变业务快照、失败保留报告时间和并发请求乱序。原研究、图表鼠标/触摸、运行器、SSE、候选导入、规则版本和反馈流程继续完整回归。未重复上一批性能基准，本批不增加实时延迟或吞吐结论。

## 容器 CI 与目标主机

新增 `CI / deployment` 执行 `bash scripts/deployment-smoke.sh`：解析 Compose、实际构建镜像、在官方 Caddy 镜像校验配置，启动默认无采样的生产应用并确认 Secure/HttpOnly/SameSite Cookie、鉴权与脱敏报告；写入研究标的后重启读回，再通过真实备份和恢复 CLI 创建新文件并切换启动，确认旧会话和命令结果失效、数据保留。脚本使用随机测试密码和独立 CI 项目卷，退出时清理临时资源；不启动公网代理或申请证书。当前提交的远端 CI 结果以 PR 中 verify 与 deployment 两个 job 的终态为准。

容器 smoke 通过也不能证明公网证书、真实代理链的 SSE、目标磁盘耐久性、主机休眠/断网、异地恢复或实际市场权限。部署步骤见 [deployment.md](deployment.md)，恢复步骤见 [operations.md](operations.md)。相关工单保留进行中，逐市场能力仍为 UNKNOWN。
