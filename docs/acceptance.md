# 首批实现验收与剩余范围

这是首批 PR 的历史验收记录。合并后的继续推进见[第二批验收记录](acceptance-v2.md)。

本批把空仓库推进为可运行的私有研究工作台。当前发布范围是合成研究闭环、确定性计算核、持久化事务和只读行情探针。真实行情持续调度、实时提醒与生产部署尚未完成，不能据此关闭全部项目工单。

## 验证环境

- Node.js 24.19.0；SQLite 实际运行库 3.53.4；Longbridge SDK 5.2.0。
- TypeScript 严格检查和 Vite 生产构建通过。
- Vitest：7 个文件、93 项测试通过，其中计算核 29、触发核 35、市场数据 15、服务端 14。
- Playwright：私有访问保护及完整研究闭环通过；使用 Chromium 153 独立可执行文件。本环境下载 Playwright 默认浏览器时 CDN 返回不完整归档，因此通过环境变量指定已有浏览器；CI 使用 Playwright 配套 Chromium。
- 无凭据行情探针实际退出 2，两市场返回 UNKNOWN；未调用真实交易接口。

具体命令见 README。CI 的最终结果以对应 PR 提交上的 `CI / verify` 为准，不能用本地结果代替。
