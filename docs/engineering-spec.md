# 工程规范 v1

本规范固化 KEJ-44 的 C01–C07，和需求 v0.2 一起使用。它是产品工程约定，不是受访者的原始交易规则。本文与 v0.2 在参考冻结、截止接收与中断恢复上的差异以本文为准。算法与资金参数仍由用户确认。

## 时间与参考

市场时间决定 K 线归属和观察期限，received_at 表示本应用入站时实际取得数据的时刻，decision_at 表示计算发生的时刻。三者不能互相替代。图表 Bar.time 以 UTC 秒序列化，其余时间使用 UTC 毫秒。

候选开始于常规开盘后 [0,15) 分钟时用1分钟，[15,60)分钟时用5分钟。整根必须位于首小时内。上一根必须同会话、同周期并紧邻候选，不得用昨日收盘前的分钟线。

参考线于候选开始后30秒内最终确认后冻结，包含边界等号。ref_ready_at 必须在所有本周期穿越比较前保存。晚于30秒到达的参考不能参加本候选，不能改用更早一根。T 为严格大于参考高点的下一个合法价格。修订已冻结参考时暂停，旧记录不改写。

盘中穿越的 x_prev 与 x_now 必须来自同一候选、ref_ready_at 之后实际收到的连续有序成交，且 x_prev<T、x_now≥T。之前实时且连续观察到的触碰可保留，补数不能制造触碰或穿越。没有供应商时序保证时不开放盘中模式。

## 截止裁决

D=min(触碰时间+15分钟, 常规开盘+60分钟)。收盘判断只接受 bar.end≤D 且 received_at≤bar.end+30秒的最终K线。定时器到 D 后禁止新候选，但必须等待最后候选的接收窗口结束；不能先不可逆地 EXPIRED 再忽略按时到达的 final。

已持久化的接收顺序决定资格，计算队列延迟不改变它；当前价格新鲜度、版本、资金与失效事实仍在决策时检查。此前已收到的止损触及优先，旧K线不能重新激活失效计划。盘中穿越不借用收盘接收宽限延长市场时间。

## 尝试与门控

| 当前状态 | 输入 | 结果 |
| --- | --- | --- |
| DRAFT | 人工确认且数据/风险合格 | 新 attempt，WAIT_RETEST |
| WAIT_RETEST | 首次合格触碰 | ARMED，冻结触碰证据和期限 |
| WAIT_RETEST/ARMED | 已知价格≤S，或合格闭合线低点≤S | INVALID，禁止新触发 |
| ARMED | 首次因果成立的突破 | 消费 attempt，保存唯一 TECHNICAL_TRIGGERED |
| 已消费 | 入场区间/追高/报价/风险全部通过 | 保存唯一 ENTRY_TRIGGERED 与提醒 |
| 已消费 | 任一门控不通过 | 保存 BLOCKED/UNAVAILABLE 原因，不能自动重试 |
| 未触发活动态 | 观察期及最终接收窗口结束 | EXPIRED |
| 未触发活动态 | 用户暂停 | USER_PAUSED |
| 活动态 | 数据缺口/顺序或修订冲突 | DATA_PAUSED，废弃连续性证据 |
| 已提醒 | 用户反馈 | TAKEN 或 SKIPPED；原事件不改写 |

恢复需要显式新 attempt 和新的 evidence_epoch。必须重新观察价格严格高于 U，再回踩；不能复用昨日收盘或断线前的上方证据。界面标注“恢复后新尝试”，不能称为会话首次。开盘后才启动首次模板时，需要有此前未触碰的完整证据。

LOD_known 仅来自当前常规会话、在决策时已知且覆盖完整的数据。3%为可选经验限制。等于通过，大于阻断。覆盖不完整时不能声称通过；事后低点不得回写历史。

## 资金与预留

金额以规范化十进制字符串存取；核心计算禁止二进制浮点金额。固定精度、合法价格/数量舍入和费用版本是规则的一部分。价格为报价币种每股；NAV/B/B_pool/Existing为基础币种；Cash为实际报价币种现金；x表示每单位报价币种对应基础币种金额。

启用时基于 Emax 保守预留并保存 approved_q。触发重算排除本计划旧预留，包含所有其他活动预留；只能减量。校验版本、预留变更、attempt消费、事件和通知必须同事务，事务内不联网。

| 情况 | 预留规则 |
| --- | --- |
| 未触发 WAIT_RETEST/ARMED | 保留 |
| 触发前 INVALID/EXPIRED/USER_PAUSED | 原子释放 |
| 触发前 DATA_PAUSED | 保留直到用户暂停或观察期结束 |
| 入场提醒等待用户反馈 | 不因首小时结束自动释放 |
| SKIPPED | 幂等释放一次 |
| TAKEN | 快照变 STALE，冻结占用；无实际价量也必须失效 |
| 确认新快照 | 新现金已含真实交易影响；原子释放已吸收交易并按固定 allocation_order 重建其余预留 |

新快照保存时比较 expectedGeneration。表单打开后发生另一笔 TAKEN 则返回409，不能覆盖 STALE。资金不足按稳定顺序缩量或暂停。B_pool只代表应用中的待完成计划风险，不代表实际全账户风险。

## 事件与历史

事件记录与用户反馈分离。按全局 attempt_id 分别唯一约束 TECHNICAL_TRIGGERED 与 ENTRY_TRIGGERED；普通 event_key 非空，避免NULL绕过去重。数据库通知队列与事件同事务提交。SSE允许重投，客户端按event_id去重；连接写入成功不等于已读。

历史快照保存行情修订、参考、锚点/计划/规则版本、实际接收时间、会话/日历、报价、资金代际、其他预留集合、费用/汇率、截止与定时器事实。不允许回放去取最新行情覆盖当时数据。回放没有生产通知出口。备份恢复一律暂停活动监测、使资金快照失效。

## 稳定原因分类

实现可细分原因码，但不得合并四类身份：技术条件不成立、必需证据不可用、门控明确阻断、用户暂停。真实数据能力保持UNKNOWN，直到按市场、部署地区、权限、周期和连续性出具证据。合成演示必须持续可见，不能升级真实能力。
